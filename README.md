# Кампус

**Интеллектуальная база знаний университета и система учебных очередей.**

Веб-приложение (и Telegram Mini App), объединяющее полнотекстовый поиск по внутренним
документам университета, систему учебных очередей и пользовательскую интеграцию с
MTUCI/TECH через токен.

> Главный модуль — база знаний и поиск по документам. Очереди и MTUCI/TECH-интеграция —
> дополнительные функции, делающие проект полезным для реального вуза.

## Описание

Система с тремя ролями (студент, преподаватель, администратор):

- **Студент** — поиск по базе знаний, просмотр очередей своей группы, запись/выход, позиция.
- **Преподаватель** — создание и управление очередями, порядок студентов, закрытие.
- **Администратор** — загрузка PDF/DOCX, статус индексации, история запросов, ошибки обработки.

## Стек технологий

| Слой | Технологии |
|---|---|
| Backend | Python, FastAPI, SQLAlchemy (async), Alembic |
| Frontend | React, TypeScript, Vite, React Router |
| База данных | PostgreSQL |
| Полнотекстовый поиск | Elasticsearch (русский анализатор) |
| Кеш | Redis (TTL 5 мин на поиск) |
| Контейнеризация | Docker Compose |
| Документация API | Swagger / OpenAPI (`/docs`) |
| Тесты | pytest (backend), Playwright (E2E) |

## Архитектура

```
frontend (React+Vite) ──► backend (FastAPI) ──► PostgreSQL   (пользователи, документы, очереди)
                                    ├──────────► Elasticsearch (чанки документов, поиск)
                                    ├──────────► Redis          (кеш частых запросов)
                                    └──────────► tech.mtuci.ru  (по пользовательскому токену)
```

## Запуск через Docker Compose

```bash
cp .env.example .env
# заполнить .env, обязательно сгенерировать TOKEN_ENCRYPTION_KEY и JWT_SECRET_KEY
docker compose up --build
```

Сервисы: backend, frontend, postgres, elasticsearch, redis. Swagger — `http://localhost:8000/docs`.

## Запуск backend отдельно

```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Запуск frontend отдельно

```bash
cd frontend
npm install
npm run dev
```

## Как работает MTUCI/TECH-токен

1. Пользователь вводит свой MTUCI/TECH-токен на странице входа.
2. Frontend отправляет токен **только** на наш backend.
3. Backend авторизуется на `tech.mtuci.ru` по токену, получает профиль и расписание.
4. Backend создаёт/обновляет локального пользователя в PostgreSQL.
5. Токен MTUCI/TECH хранится **только в зашифрованном виде** (Fernet).
6. Backend выдаёт собственный JWT; реальный MTUCI/TECH-токен на frontend не возвращается.

Интеграция — пользовательская привязка токена. Официальный SSO МТУСИ может быть подключён позже.

## Почему не используем логин/пароль ЛК МТУСИ

Мы не запрашиваем и не храним логин/пароль от личного кабинета МТУСИ и не используем ЛК
как основной источник авторизации. Используется только пользовательский MTUCI/TECH-токен —
это безопаснее и не требует доверять приложению учётные данные ЛК.
